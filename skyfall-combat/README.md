# SKYFALL Combat — Phase 1

Original browser-based arcade jet-flight prototype.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run
npm install
npm run typecheck
npm run build
npm run dev

Open port 5173 in GitHub Codespaces.

## Controls
- W/S: pitch
- A/D: roll
- Q/E: yaw
- Arrow keys: pitch and roll
- = / +: increase throttle
- -: decrease throttle
- Shift: boost
- R: level-out assistance
- Mouse: steering while pointer lock is active

Weapons and multiplayer are not implemented in Phase 1.
